Auto Steer Logic

The bot geometrically follows the track center line. Participant parameters influence how well it executes — not whether it knows the path.

float Driver::autoSteer() {
    // Get the angle of the track ahead
    float targetAngle = RtTrackSideTgAngleL(&(car->_trkPos));
    
    // Difference between track direction and car heading
    targetAngle -= car->_yaw;
    
    // Normalize to -PI .. PI
    NORM_PI_PI(targetAngle);
    
    // Normalize to -1 .. 1 and apply participant steer strength
    return (targetAngle / car->_steerLock) * config.steer_strength;
}

5-Phase Turn Logic

Every corner has five distinct phases. Each phase has its own logic for throttle, brake, and steer.

01
Approach
Full throttle. Lift off 20m before brake point to settle the car.
02
Braking
Trail braking — hard at entry, taper off toward turn-in. Throttle zero.
03
Turn-In
Braking overlaps steering. Car rotates toward apex. Snap oversteer risk.
04
Apex
Minimum speed. Zero throttle, zero brake. Pure cornering. Most grip-sensitive.
05
Exit
Progressive throttle as car unwinds. Too early = oversteer. Too late = slow.
void Driver::drive(tSituation *s) {
    float pos      = car->_distFromStartLine;
    float steer    = autoSteer();
    float throttle = config.driver.throttle_aggression;
    float brake    = 0.0f;

    for (auto& corner : config.corners) {

        // Phase 1 — Approach lift
        if (pos > corner.brake_start - 20.0f && pos < corner.brake_start) {
            float dist = corner.brake_start - pos;
            if (dist < 20.0f) throttle = 0.5f;
        }

        // Phase 2 — Trail braking
        if (pos >= corner.brake_start && pos <= corner.turn_in) {
            float p = (pos - corner.brake_start) / (corner.turn_in - corner.brake_start);
            brake    = corner.brake_strength * (1.0f - p * 0.4f);
            throttle = 0.0f;
        }

        // Phase 3 — Turn-in with overlap braking
        if (pos >= corner.turn_in && pos <= corner.apex) {
            float p = (pos - corner.turn_in) / (corner.apex - corner.turn_in);
            brake    = corner.brake_strength * 0.6f * (1.0f - p);
            throttle = 0.0f;
        }

        // Phase 4 — Apex coast
        if (pos >= corner.apex - 5.0f && pos <= corner.apex + 5.0f) {
            brake = throttle = 0.0f;
        }

        // Phase 5 — Progressive exit throttle
        if (pos >= corner.throttle_exit && pos <= corner.exit_complete) {
            float p = (pos - corner.throttle_exit) / (corner.exit_complete - corner.throttle_exit);
            throttle = config.driver.throttle_aggression * p;
            brake    = 0.0f;
        }

        // Safety net — corner speed limit
        enforceCornerSpeed(corner, throttle, brake);
    }

    // Slip punishment
    applySlipPenalty(steer, throttle);

    car->ctrl.steer    = steer;
    car->ctrl.accelCmd = throttle;
    car->ctrl.brakeCmd = brake;
    car->ctrl.gear     = autoGear();
}

Slip Physics

Slip happens at the physics level — auto steer cannot override it. Bad configs are genuinely punished by the sim engine.

void Driver::applySlipPenalty(float &steer, float &throttle) {
    
    // Lateral slip — car sliding sideways
    float lateralSlip = fabs(car->_wheelSlipSide[0] 
                           + car->_wheelSlipSide[1]) / 2.0f;

    // Longitudinal slip — wheels spinning or locking
    float longSlip = fabs(car->_wheelSlipAccel[0] 
                        + car->_wheelSlipAccel[1]) / 2.0f;

    if (lateralSlip > 2.0f) {
        throttle *= 0.2f;   // cut power when sliding
        steer    *= 0.5f;   // steering less effective on sliding tyres
    }

    if (longSlip > 3.0f) {
        throttle *= 0.3f;   // wheelspin — cut throttle
    }
}

// Corner speed safety net
void Driver::enforceCornerSpeed(Corner& corner, float &throttle, float &brake) {
    float speedKmh = car->_speed_x * 3.6f;
    float pos = car->_distFromStartLine;

    if (pos > corner.turn_in && speedKmh > corner.corner_speed_limit) {
        float excess       = speedKmh - corner.corner_speed_limit;
        float emergencyBrake = fmin(excess / 50.0f, 1.0f);
        brake    = fmax(brake, emergencyBrake);
        throttle = 0.0f;
    }
}
